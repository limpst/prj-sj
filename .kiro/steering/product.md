# Product

건축물 안전관리 플랫폼. 첫 모듈(M1)은 정부세종청사 5·6동 방문자 동선(Wayfinding) 시범.

## 목표
- 방문자가 B(BRT 북측)·S(3동 인근 버스)·P1·P2(주차 보행출구)에서 R5(3·5동 종합안내실)·R6(6동 통합안내실)까지 덜 헤매게 한다.
- 경로는 바꾸지 않는다. 안내의 발견 → 선택 → 확인 → 도착 순서를 바꾼다.

## 불변 규칙
- 색상 = 도착 수단, 숫자 = 목적 동. 색상만으로 정보를 전달하지 않는다 (숫자·문자 병기).
- 크기 위계: 동번호 > 방문접수 > 보조 영문.
- 현장 사인 = 앱 위치 확인점 = 의견 수집 지점. 모두 승인대장 같은 버전에서 파생.
- 직원 전용 출입구·연결 지붕을 방문자 지름길로 안내하지 않는다. 안내는 접수처까지만.
- EAST 중 Easy·Attractive·Timely 만 사용. Social(군중) 문구와 근거 없는 "대부분 이용" 표현 금지.
- 도상 px 는 m·초가 아니다. p·r 은 가정값이다. 효과 수치를 예측처럼 표현하지 않는다.
- 상시 GPS·자동 이탈감지 없이 QR·수동 코드로만 위치 갱신. 개인 식별정보 수집 금지.
- 안전·대피 표지는 범위 밖(별도 표준 체계 유지).

## 범위 밖
- 앱 실제 개발·배포는 후속 사업 승인 전까지 프로토타입만.
- M2(정기점검)·M3(균열 모니터링)·M4(Digital Twin)는 설계 메모만.
